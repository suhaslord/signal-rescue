# signal rescue

mobile measurements and an outage recovery simulator, inspired by rural connectivity in india.

[open app](https://signal-rescue-suhasaug2011-2968s-projects.vercel.app/)

zoom anywhere for local measurements, compare quarters, or start with chittamur and lathrop. then test tower failures, backup power, repairs and a temporary relay.

[measurement source and limits](DATA.md). simulation uses assumed towers and users.

run the full app with `vercel dev` (Python dependencies in requirements.txt)  
test: `npm test`
