All options use reassignment. Repairs and relay placement use the current range extension. Relay reach is in map units, not metres. Placement tests 144 grid points; it assumes an available power supply and backhaul connection.

method

Dots are simulated users. A user needs a tower within range and a free capacity slot. The outage uses nearest-first assignment. Reassignment searches for a maximum matching: it moves existing connections when necessary to make room for another user. Range extension enlarges tower reach by the selected percentage; “both” also reassigns users.

Capacity and range are hard limits. Recovery cannot create coverage when every tower is off. Layouts are repeatable; changing user count or capacity keeps your tower outages. This geometric model does not include interference, terrain, or actual 5G radio protocols.

Everything runs locally in your browser. No real coverage data is used.

This project explores outage recovery motivated by rural connectivity problems in India. A repair ranking estimates connections restored, not repair cost or travel time. Range extension is hypothetical; it does not model the power, interference or regulatory limits of a real radio network.
